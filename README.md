# もちろぐ（Web版）

買う予定のものと買った記録を、用途ごとのリストで管理するアプリです。

公開URL: https://kazuuui.github.io/mochimono-list/

## 機能

- 品目の追加・編集・削除、購入済みのチェック
- 用途ごとのリスト切り替え（マイリスト＋テンプレ5種＋自作リスト）
- 持ち物テンプレ：キャンプ／海外旅行／国内旅行／登山／夏フェス
- 並び替え（登録順・購入日・金額、昇順降順の切り替え）
- 絞り込み（未購入・購入済・カテゴリ）
- ダークモード（端末設定に追従、手動切り替えも可）
- 表示幅と文字サイズの調整

## データについて

入力した内容はブラウザの localStorage にのみ保存されます。
サーバーには送信されません。詳しくは[プライバシーポリシー](privacy.html)をご覧ください。
