プライバシーポリシー

もちろぐ（持ち物・購入リスト）

もちろぐは、利用者の個人情報を収集しません。入力された内容は利用者の端末内にのみ保存され、 開発者を含む第三者が閲覧することはできません。

1. 対象

本ポリシーは、iOS アプリ「もちろぐ」および Web 版 （https://kazuuui.github.io/mochimono-list/） に適用されます。

2. 収集しない情報

本アプリは、以下をはじめとするいかなる情報も収集・送信しません。

  • 氏名、メールアドレス、電話番号などの個人を特定する情報
  • アカウント情報（そもそもアカウント登録の仕組みがありません）
  • 位置情報
  • 連絡先、写真、カレンダーなど端末内の他のデータ
  • 利用状況の統計、広告識別子、その他の追跡のための情報

3. 入力したデータの保存先

品目名・カテゴリ・金額・購入日・メモ・購入済みの状態など、利用者が入力した内容は、 すべて利用者の端末内にのみ保存されます。

  • iOS アプリ：端末内のアプリ領域（SwiftData）
  • Web 版：ブラウザの localStorage

これらのデータが開発者のサーバーや外部サービスに送信されることはありません。 開発者がその内容を知る手段もありません。

データは端末ごとに保存されるため、別の端末には引き継がれません。 アプリを削除した場合、または Web 版でブラウザのデータを消去した場合、 保存された内容は失われます。復元はできませんのでご注意ください。

4. 第三者への提供

収集する情報がないため、第三者への提供、共有、販売は一切ありません。

5. 広告・アクセス解析

本アプリは広告を表示しません。アクセス解析ツールや行動追跡の仕組みも組み込んでいません。 iOS アプリにはネットワーク通信を行うコードが含まれていません。

6. Web 版のホスティングについて

Web 版は GitHub Pages 上で公開しています。ページの閲覧時には、 ホスティング事業者である GitHub, Inc. が、 サーバーの運用・セキュリティ確保のために IP アドレスやアクセス日時などの 技術的な記録を取得する場合があります。これは開発者が設定したものではなく、 開発者がその記録を参照することもできません。

詳しくは GitHub のプライバシーに関する声明 をご確認ください。

7. お子様の利用について

本アプリは年齢を問わず利用できます。個人情報を収集しないため、 お子様が利用された場合も情報が集められることはありません。

8. 本ポリシーの変更

機能の追加などにあわせて本ポリシーを変更する場合があります。 変更した場合は、このページに掲載するとともに更新日を改めます。

9. お問い合わせ

本ポリシーまたは本アプリについてのご質問は、以下からお願いします。
